# 祖国人街区沙盒 · MVP 需求文档

版本：1.3 · 更新日期：2026-10-14 · 状态：MVP 已实现，持续改善角色与整体拟真感；已接入独立普通跑/快跑。

配套文档：[实施计划](./IMPLEMENTATION_PLAN.md)。本文件定义“做成什么”，实施计划定义“如何实现和验证”。

## 1. 产品目标

玩家扮演具有祖国人能力的普通人形角色，在一个紧凑的 3D 街区自由飞行、扫射、击飞 NPC、破坏环境，引发逐级升级的城市追捕，体验压倒性的力量。

MVP 成功标准：飞行容易操控，四种能力可持续使用且反馈不同，攻击能真实改变 NPC 和指定场景物件，街区能持续游玩并完整重置。

“祖国人的所有能力”在本版明确收敛为：飞行、镭射眼、超级力量、超级速度和无敌。超级听觉、透视等未讨论能力不纳入本版。

## 3. 游玩流程与界面（R01）

1. 启动本地服务，通过浏览器打开游戏。
2. 显示资源加载进度；加载完成后显示“开始游戏”和操作说明。
3. 点击开始，锁定鼠标，从街道安全点进入游戏。
4. 自由探索、使用能力、攻击 NPC 和环境；追捕随玩家行为升级。
5. 停止攻击和破坏，追捕逐级下降；平民逐渐补充，世界损毁保留。
6. 按 Esc 暂停并释放鼠标；暂停菜单提供继续和重置街区。
7. 重置恢复初始地图、NPC、玩家位置、追捕等级和所有临时效果。重置后停留暂停界面，点击继续恢复。

实现默认：中文 UI；失去焦点、切换标签或丢失鼠标锁定时暂停，清除按键状态，所有游戏计时器停止。恢复必须通过点击，不自动夺回鼠标。资源加载失败显示失败项和重试入口。

不显示玩家血条、能量条或冷却条；可显示简短的“无敌”状态。开发性能面板不占用常规游玩界面。

## 4. 操作、移动与镜头（R02）

| 操作 | 输入 |
|---|---|
| 地面移动／空中水平移动 | WASD |
| 视角与瞄准 | 鼠标移动 |
| 地面跳跃／行进跳跃 | 空格，配合 WASD 或 Shift 保持前进 |
| 起飞／退出飞行 | F |
| 飞行上升／下降 | 空格／Ctrl |
| 地面冲刺／飞行加速 | 按住 Shift |
| 持续镭射 | 按住鼠标左键 |
| 重拳 | 鼠标右键 |
| 空中砸地 | Q |
| 暂停、释放鼠标 | Esc |

- WASD 以镜头在水平面上的朝向为参照，斜向移动速度归一化；镜头俯仰用于观察和瞄准，上升下降由独立按键控制。
- 鼠标控制镜头偏航与俯仰；镜头避免穿入建筑，并保持角色与瞄准方向可读。
- 起飞进入空中悬停；松开方向键平滑减速至停下；高速飞行呈身体前倾姿态。
- 地面和行进中空格跳跃；保留水平动量，可在空中调整方向，不做二段跳。飞行中空格仍为上升。
- F 退出飞行进入自然下落，接地后从原片段接触部分恢复，不重播空中下降；Q 触地采用同一收势。落地恢复步行；下落中可再次 F 悬停。自然落地不触发砸地攻击。
- Q 从空中主动快速下降，落地触发砸地；地面按 Q 不触发。
- 飞行下降接触地面或屋顶后回到地面状态，F 可再次起飞。
- 高速撞到建筑主体，停止朝障碍物运动并给出短促撞击反馈；切向移动允许脱离墙面。撞击可破坏面板后，只在确有通路时继续穿过。
- 地面冲刺和飞行加速通过动作、风线和适量视野变化表现；不使用强制长时间镜头晃动。
- 游戏捕获输入时屏蔽页面滚动、右键菜单及 Ctrl+点击引起的菜单冲突。

## 5. 能力与命中规则

### 5.1 通用规则（R03）

- 玩家不可被杀死，没有生命值消耗、能量消耗或额外技能冷却。
- 重拳与砸地包含必要的动作时间，不能在同一帧无限重复触发。
- 实现默认：重拳按下触发一次，砸地按下触发一次；镭射按住持续生效。
- 重拳和砸地执行时暂停镭射，动作结束后若左键仍按住则恢复；砸地结束前不允许重拳或 F 中断。
- 攻击不得穿透完整建筑。范围伤害需检查遮挡，不能隔着完整墙体杀伤 NPC。
- 死亡与摧毁只结算一次；尸体、已碎墙面和废车不重复产生击杀或破坏积分。
- 敌人攻击只提供枪口、曳光或命中特效，不伤害或强制打断玩家，不产生追捕积分。
- 碎块默认只作物理和视觉反馈，不再造成连锁伤害；被玩家击飞的车辆可对活体 NPC 造成一次有效碰撞伤害，需归因给玩家。

### 5.2 镭射眼（R04）

- 双眼持续发射红色光束，终点朝向中央准星选定的世界位置；地面、悬停和加速飞行中可使用。
- 准星先选定目标，再检查眼睛到目标的实际遮挡，防止镜头探出墙角后隔墙攻击。
- 光束被最近有效障碍截断，不穿透完整墙体；墙面摧毁后可继续命中其后目标。
- 对活体 NPC 持续伤害直至死亡；对可破坏墙面、物件、车辆持续造成损伤。
- 命中显示接触亮点、少量粒子；命中 NPC 配少量血液，命中不可破坏主体仅有命中特效。

### 5.3 超级力量（R05）

- 重拳：角色朝瞄准方向出拳，命中近距离前方范围；同一拳对同一目标结算一次，可击飞 NPC、推动或掀翻车辆、摧毁指定物件。
- 空中砸地：快速向下落到首个可站立表面，在落点产生冲击圈、少量碎屑与短促镜头反馈，对附近可见目标造成范围伤害和径向冲量。
- 屋顶砸地不穿透楼板伤害楼下 NPC；砸到建筑主体不造成整栋倒塌。

### 5.4 超级速度（R06）

- 地面按住 Shift 配合移动进入高速冲刺，松开恢复正常速度。
- 高速移动接触 NPC 时击飞并伤害，接触可破坏小物件时破坏。
- 空中 Shift 配合移动进入加速飞行；高速飞行撞击也可伤害 NPC、破坏指定面板。
- 同一次接触不能每帧重复伤害；必须脱离后重新发生有效碰撞，或满足配置的重复命中保护间隔。

## 6. NPC 与三级追捕

### 6.1 平民与死亡（R07）

- 平民沿人行区域行走，可短暂停留，避免持续穿墙或原地堆叠。
- 附近发生攻击、击杀或破坏时，平民沿可走区域远离危险位置；危险消退后恢复日常行走。
- 平民与敌人都可受伤、死亡；死亡立即停止 AI 和主动攻击，身体受冲量倒地或击飞。
- 不要求完整关节布娃娃，允许用简化物理身体驱动模型倒地，但不能只把人物直接隐藏来代替受击死亡表现。
- 平民减少后，在视野外、远离玩家的有效边缘出生点逐批补充到预算；没有合适位置就延迟，不在玩家面前突然生成。
- 尸体、血液和动态碎块短暂保留后清理；清理不使破坏面板复原。

### 6.2 追捕（R08）

| 等级 | 场面与行为 | 初始敌人目标数 |
|---|---|---:|
| 0 | 无追捕 | 0 |
| 1 | 少量警察到场，接近并射击 | 4 |
| 2 | 更多警察，更密集射击 | 8 |
| 3 | 步兵军队加入，外观与火力更明显 | 12 |

- 数量为当前敌人总预算，不是每次升级叠加的数量；最高级默认 4 名警察和 8 名士兵。
- 对活体或完整可破坏物件的有效攻击提高追捕热度；挥空和朝天空发射镭射不增加热度，但主动攻击仍会延后追捕消退。
- 持续光束攻击热度按固定频率结算，击杀和摧毁额外结算一次，避免按帧涨满。
- 高等级敌人可以分批补充损失，数量始终受限；出生点采用视野外检查。
- 地面敌人沿可走区域接近玩家，存在视线时射击；玩家在空中时可向上瞄准。超出射程或被遮挡时移动或搜索，不飞行、不穿墙。
- 玩家停止所有主动攻击、有效撞击和破坏后启动消退计时；敌人的攻击不重置计时。降级后多余敌人撤离，不在眼前瞬间消失。
- 热度归零后剩余敌人停止追击并撤离；如果撤离路径暂不可用，延迟到视野外清理。

## 7. 场景、破坏与恢复（R09）

- 街区有可辨认的路口、人行道、巷道、不同高度屋顶，便于飞行与降落。
- 可破坏区域使用独立面板：窗户、围墙、外侧挡板和少量临街立面；完整、受损和摧毁状态可辨认。
- 打碎后生成碎片并移除相应阻挡，露出巷道或简易空腔。不可保留整栋粗碰撞盒挡在承诺可穿行的缺口后方。
- 路灯等小物件可以摧毁。建筑主体、道路、屋顶不整体坍塌。
- 停放车辆为物理交互物体，可击退、翻倒，伤害达到阈值后显示损毁状态；无需可驾驶、爆炸连锁或车身实时变形。
- 车辆休眠后保留位置和损毁外观；碎块清理后墙体缺口保留。
- 水平边界和高度上限前显示提示并逐渐削减向外速度；保留向内与切向移动，避免玩家卡住。NPC、车辆也不得无限漂出模拟区域。
- 手动重置恢复全部世界状态；刷新页面同样从初始世界开始，不存档。

## 8. 实施默认值：可调，不是额外用户承诺

以下用于避免代码生成时遗漏规则。集中配置，实测后可调整数值；调整不得删除已确认能力或改变玩法范围。

| 参数 | 初始值 |
|---|---|
| 正常地面速度／冲刺速度 | 6／24 米每秒 |
| 普通飞行／加速飞行／升降速度 | 12／40／10 米每秒；组合输入限制总速度 |
| 加减速过渡 | 约 0.25–0.5 秒 |
| 飞行高度上限／边界缓冲宽度 | 地面以上 80 米／水平 20 米、顶部 10 米 |
| NPC 生命值 | 平民 50、警察 80、士兵 120 |
| 镭射 | 射程 100 米，伤害 200/秒，逻辑伤害间隔 0.1 秒 |
| 重拳 | 距离 3 米，前方约 90°，伤害 150，动作约 0.45 秒 |
| 砸地 | 下降速度 40 米/秒，半径 8 米，伤害 200，落地收势约 0.6 秒 |
| 高速碰撞 | 速度至少 18 米/秒生效，伤害 150；同目标接触保护 0.5 秒 |
| 热度阈值 | 1–29 一级、30–79 二级、80–100 三级，0 无追捕 |
| 热度增量 | 有效攻击 +1（同目标每秒最多一次）；击杀 +10；摧毁物件/墙面 +5；车辆 +10 |
| 消退 | 无主动攻击或有效破坏 15 秒后，每秒减 5 热度；再次攻击重置等待 |
| 补充 | 平民每 5 秒尝试补充至多 2 人；敌人每 5 秒尝试至多 2 人；均须满足安全出生条件 |
| 生命周期 | 尸体 12 秒、动态碎块 6 秒、血液 8 秒；资源池满时提前清理最旧效果 |
| 场景内容预算 | 6–10 栋建筑，至少 8 处可破坏区域、8 个小物件、6 辆停放车辆（小物件按街区布局由初始 10 调为 8） |

墙面、小物件和车辆生命值、冲量与质量由实施调参，但重拳和高速撞击必须能明显影响车辆，镭射必须能在可感知时间内完成破坏。

## 10. 明确不做

多人联机、账号后端、存档、线上部署、手机触屏、手柄、键位编辑器、剧情与任务、成长系统、玩家死亡、能量条、声音、抓取投掷、慢动作、坦克和直升机、交通与驾驶、完整室内、任意切割、结构坍塌、肢解、完整披风布料仿真。

其中少量血液、三级步兵追捕、真实模型与动画、车辆物理互动均是本版要求，不得在实施时默认为后续版本。
