# Graffiti 全城接入

2026-10-22。用户认可免费 Graffiti Stairs 的本机质感后，明确要求接入原地图、扩展全城，并授权使用 Blender MCP 修改现有素材。本轮已实现约 **200×200 米可玩核心**，新全图视觉仍交用户审看，未将“GTA 成品水准”写为已验收结论。

## 当前入口与内容

最终本机生产入口：[新版默认街区](http://127.0.0.1:5197/)。5194 的 `?scene=graffiti` 是历史小图服务；根源码在私有资源存在时默认加载新城，`?scene=graffiti` 保留原小图，`?scene=legacy` 回看旧密度样板；无私有包时回退旧场景。5195 是独立主角验收副本，不覆盖它。已将用户现有 IAB 标签从 5194 小图导航到 5197；菜单已加载完成，捕获鼠标需用户手动点击“进入街区”。实操验收使用 Chrome，未把 IAB 自动点击被拒算作游戏操作通过。

- 16 个街坊，65 栋核心建筑（60 个原型实例和原楼梯街角的 5 栋），15 庭院；外围 336 栋同套 L2 建筑仅作背景，不能越过原核心边界游玩。
- 保留原楼梯/涂鸦/栏杆组合，位于核心东侧、坐标约 `(34,43)`；从初始位置沿主路向东、转入东侧街坊可找到。空中俯看也可辨认。
- 保留 20 平民、8 车辆（公交/轿车/两轮车）、三级追捕和既有能力。两处独立玻璃商铺可破门进入，8 处庭院门可打通；新增街边座椅、垃圾桶和庭院陈设可分别损毁。
- 原白模主体和旧棋盘高楼退出新城视野，江岸、桥与高架仍为既有背景。主路人行道约 6 米，次路净宽 7.2 米、两侧人行道各 2.4 米；64 块铺地互不重叠。
- 60 处封闭卷帘入口是立面外观，未宣称所有楼都可进入。独立楼根据最低完整窗台下沉，修复原山坡基座在平地露出的问题；一处首层窗户转换为入口，墙面射线确定门的位置，台阶按实际人行道标高放置。

使用已安装的 **Blender MCP 2.2.2 / Blender 5.2.2** 拆出六类完整建筑，保留源 UV 和材质名，建立 L0/L1/L2（原面数/约 22%/约 6.5%）；不改原楼梯组合。实例按街坊朝向和有限高度差布置，远景固定 L2。运行时共享几何/材质，按相机距离 36/85 米切换 LOD。实例矩阵包含量化还原变换，实例缓冲在删除/重置时释放。

源工程：`.asset-source/graffiti-city/city.blend`；脚本：`scripts/build-graffiti-city.py`、`scripts/pack-graffiti-city.py`。通过 MCP 执行第一份脚本，再运行 `python3 scripts/pack-graffiti-city.py`。输入是由原试用管线导出的 `.artifacts/graffiti-stairs/raw/geometry.glb`，原 FBX 和 KTX2 生成步骤见原记录。运行路径为 `public/assets/graffiti-city/`，原纹理仍在 `public/assets/graffiti-stairs/`，510 张 KTX2 共用，未按楼数复制纹理。

## 明确边界

原楼梯多段净宽约 1.96–2.26 米，当前地面大 Ball 直径 2.2 米，窄段步行仍未闭环；未擅改主角碰撞。全城街道/支路通行与楼顶落地已另测，不能用它们宣称原窄梯修好。新窗墙仍是静态建筑，只有独立门、商铺玻璃和小物沿用局部破坏规则；不是全楼拆毁或全楼室内。六个来源原型仍有重复和空白后墙，外围桥岸仍为景观；整体画面仍须用户审看。主角足底 5 厘米和 A2 自然度的未验边界继续保留。
