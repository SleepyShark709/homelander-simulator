## 脚本与结果

- `npm test`：12 个规则/物理/模型测试。
- `scripts/smoke.mjs`：本地加载、实际飞行操作、截图。
- `scripts/integration.mjs`：10 项主要流程检查；`.artifacts/integration.json`。
- `scripts/extended.mjs`：7 项补充检查；`.artifacts/extended.json`。
- `scripts/performance.mjs`：30 秒预热、两组 120 秒采样及继续运行，含三次重置；`.artifacts/performance.json`。

`.artifacts/` 为本地生成证据目录，不进入版本控制。测试中不存在的结果不得根据代码推断为已通过。

- `scripts/final-smoke.mjs`：7 项最终补测，包含 Ctrl、失焦、相机、高速穿过破坏面板、向空中射击和生产构建；`.artifacts/final-smoke.json`。
- `scripts/visual-regression.mjs`：8 项拟真角色与玩法回归，包括独立骨架、前倾飞行、双眼镭射和稳定资源基线；`.artifacts/visual-regression.json`。
- `scripts/visual-benchmark.mjs`：普通与三级追捕各 20 秒短时采样；`.artifacts/visual-normal.json` 与 `.artifacts/visual-stress.json`。
