# Graffiti 全城接入与密度调整

2026-10-22。用户认可素材质感后授权扩建全城，随后指出街坊空旷、人行道太宽、建筑占地偏小。本轮已按实际占地重排：**主路人行道 6→3 米，核心建筑 65→171 栋，街墙连续成排**。新整体视觉仍交用户审看，未宣称 GTA 成品画面已获验收。

## 当前入口与空间

本机生产入口：[默认街区](http://127.0.0.1:5197/)。5194 的 `?scene=graffiti` 是旧小图；5195 是独立主角验收副本，未覆盖它。根源码在私有资源存在时默认加载新城，`?scene=graffiti` 保留原小图，`?scene=legacy` 回看旧密度样板；无私有包回退旧场景。

- 可玩核心仍为约 200×200 米、16 街坊，171 栋核心建筑（166 个独立原型实例及原楼梯组合 5 栋），外围 336 栋同套 L2 仅作远景。
- 15 普通街坊按米制包络实测拼接四侧街面，补齐街角与内部翼楼。独立原楼梯角保持几何，移至约 `(39,48.5)`，空缺的两边也补上同套建筑。
- 主路人行道和外缘人行道均为 3 米，次路两侧各 2.4 米；主路车行道 20 米、次路 7.2 米保持。64 块铺地无重叠，尺寸直接读取同一份布局元数据。
- 保留 15 个有入口的庭院、8 处可打通门、2 处破玻璃可进入的商铺。主要庭院净空矩形约 104–151 平方米；门口净宽 3.81–4.6 米。原 16 套座椅/垃圾桶移入庭院边缘，路灯移至车道边缘，导航/增援点同步至 3 米人行道中心，避免堵路。
- 20 平民、8 辆原三类车辆、全部现有能力与三级追捕保留。当前 42 段主角及取消 MotionTrail 状态保持。

## 来源、加工与资源

来源/许可和原 FBX 哈希见[原试用记录](GRAFFITI_STAIRS_TRIAL.md)，候选检索见[素材清单](SCENE_ASSET_CANDIDATES.md)。未采用新付费资源；使用 **Blender MCP 2.2.2 / Blender 5.2.2** 修改现有六类建筑和布局，原 UV/PBR 与楼层/门窗高度保留。长米色楼仅水平长度由 28.44 米离线适配至 26.25 米，约短 7.7%，让街角可容纳完整侧翼；未放大角色或改人物碰撞。原楼梯组合不做此缩放。

源工程 `.asset-source/graffiti-city/city.blend`；构建脚本 `scripts/build-graffiti-city.py` 经 MCP 执行，随后 `python3 scripts/pack-graffiti-city.py`。输入 `.artifacts/graffiti-stairs/raw/geometry.glb` 的生成见原试用管线。`layout.json` 同时记录楼位、街坊边界、铺地边界、庭院和入口，运行时共享六类 L0/L1/L2，36/85 米切换，远景固定 L2。

运行目录 `public/assets/graffiti-city/`，共享原 `graffiti-stairs/` 的 510 张 KTX2，不按实例复制纹理。BIN **161,816,288 字节**，SHA-256 `67c72ccb9c20eb66254e8f25ea25b49c63c807a44f1fdd2b256013e6583fed34`；Blender 原库 `b12a3b9a247207824e858af3d4987b22ddeea0d236081e32b204f0eb7da4a42b`，脚本摘要 `e8a548ae3c22aff8c94d83e86657d2549edc9068ec2b8d4190aafd844195fced`。比原 65 栋版本体积基本不变，数量增长主要是实例矩阵。

碰撞采用主体盒、原 Float32 精确屋顶和楼梯网格。屋顶保留局部坐标，位置/旋转通过 Rapier collider pose 设置，避免将顶点先转换为大世界 Float32 后在屋脊产生微缝；两处半周转向的屋顶失败已修复。实例缓冲、独立陈设材质按既有生命周期释放，共享缓存不误释放。

Royalty Free 不等于 CC0 或允许重新上传场景。两个 Graffiti 目录与源工程仍留本机忽略路径，不进公开 manifest，无新增购买、提交、推送或部署；不记录邮箱/领取凭据/token。换机需合规复制本机私有输入或从已领取来源恢复。

## 本轮验证与实机证据

- 类型检查、新城相关 CPU 测试通过。25 项真实资产检查通过，包括资源引用、LOD/屋顶、无相交脚印、每普通地块占地≥70%、沿街连续率≥78%、入口净宽≥3.6 米。
- 14 项真实几何/Rapier 检查通过：196 个净空且连通导航点、20 个独立出生点、8 车、166 个楼顶与实际屋顶一致、全部封闭入口贴墙、庭院门移除后保留完整玩家宽通道。
- Chrome / Metal、1440×900、当前 42 段主角：21 项实机检查全部通过。键鼠覆盖主路/三段支路、跳跃、飞行/Q、屋顶降落、完整门阻挡→镭射→入院、开玻璃入店；独立 fixture 覆盖三类车损毁/冲量及追捕向上射击。暂停冻结双时钟，三次重置均为 29 刚体、720 碰撞、20 平民、0 敌人/临时效果，736 几何/597 纹理稳定，无运行错误。
- 最初穿门用例从外围庭院向外走，在 20 米边界缓冲区被限速，固定 650ms 未穿过。已改为从街道进入庭院验证实际入口；未放宽穿过距离，也未修改角色边界/碰撞。屋顶落地等待实际恢复结束后再开始独立交互用例。
- 干净导出安装/全套测试/生产构建与 smoke：随后补入本轮实际结果。未追加性能长测，旧小图约 60FPS 不代表新全城；Safari、移动端、互联网加载未测。

最终图片与 21 项报告：`.artifacts/graffiti-city/density-revision/game-final/`，含 `city-aerial.png`、`intersection.png`、`street-front.png`、`stairs-front.png`、`low-flight.png`、`roof-landing.png`、破门/店内图和原始录像。与 `.artifacts/graffiti-city/final-integrated/` 的 65 栋版同机位对照。独立只读视觉核验确认密度明显改善，所见范围未发现新增必修穿插/漂浮；仍不代替用户整体画面认可。

## 保留的边界

原窄梯净宽约 1.96–2.26 米，地面 Ball 直径 2.2 米，窄段步行仍未闭环；飞行 Ball 直径 3.2 米。新街道、庭院入口和屋顶已分别检查，不能据此宣称窄梯已修复。独立卷帘为封闭立面外观，建筑窗墙仍静态；不是全楼室内或全楼拆毁。六类原型仍有重复、空白后墙和源玻璃表现，桥岸/高架仍为背景；主角 A2 足底/自然度未验边界继续保留。65 栋首版证据留作历史，本轮结论以上述新目录为准。
