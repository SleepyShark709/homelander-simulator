### 保留的失败与实际边界

- 初次 Blender 工厂重置断开 MCP、过大的未量化模型、招牌遮挡、垃圾桶底面与黑砖问题均已修复后复测；保留原日志/截图，未放宽资源阈值。
- 早期路线直穿 NPC/停车位置被真实碰撞阻挡，以及飞行制动的测试停点过近；调整操作路线和提前松键后完成连续路线。没有修改人物运动参数来通过场景测试。
- 开发服务在目录移动/并行构建时曾热重载，废弃该录像，改用独立冻结副本。一次 Python 鼠标 API 错误已修复，最终 30 项完整重跑通过。
- 既有 `final-smoke.mjs` 将飞行起点固定在旧玻璃后侧，导致“未破窗”失败；改为面板前 5 米、1.8 米低空起点后七项通过。失败报告为 `production/fixture-failed.json`，未改运行玩法。
- 桥、江面与高架保持界外背景；核心北端远眺点可达，没有把背景桥计为可玩桥面。其他地块完整美术与桥头/河岸接驳仍留 D7。
- 本轮未追加 GPU 性能长测或 Safari 验收，不沿用江湾历史帧率；构建保留既有大 chunk 提示。全图白模与局部简化背景不是全图美术完成。
