# 拟真改版验证 · 2026-10-10

对应 [VISUAL_UPGRADE.md](./VISUAL_UPGRADE.md)。本报告使用当前 MakeHuman 蒙皮角色和新版城市；初版方块角色的历史数据在 [VALIDATION.md](./VALIDATION.md)。

## 环境与方法

- 本机 MacBook Pro，Apple M2 Pro，32 GB，macOS 26.6.2；Node 22.22.0、npm 10.9.4。
- 本机 Chrome 155，由 Playwright 驱动，headless、ANGLE Metal / Apple M2 Pro，画布 1440 × 900、DPR 1。
- 开发接口用于摆放目标、初始化追捕和固定步推进；实际键鼠用于飞行、加速、镭射和暂停。资源数量检查使用相同视角，避免把相机首次看到的新几何误判为泄漏。

## 已完成检查

- `npm run typecheck`、`npm test`、`npm run build` 通过；12 项测试涵盖规则、真实物理和人形 GLB。模型检查包括骨骼、动作、权重归一化与实际衣服/靴子网格。
- `scripts/visual-regression.mjs` 的 8 项检查全部通过：角色独立骨骼、前倾飞行和风线、暂停冻结、双眼挂点实际镭射击杀、重拳/砸地/面板/车辆、12 人追捕与完整撤离、4 次稳定重置、无运行时异常。
- 4 次重置均恢复 29 刚体、87 碰撞体、20 平民、0 敌人、0 临时效果；固定视角均为 240 几何、36 纹理。
- 修复撤离单位滞留旧追击目标和局部人群阻塞；撤离到街区出口后淡出，淡出关闭深度写入，透明状态切换更新材质。
- 人物动画不串到其他角色；角色删除释放自有材质、附件几何和骨架，城市重建释放自有表面纹理，共享源资产继续保留。

追捕消退场景通过固定物理步推进约 103 秒模拟时间；这项测试的墙钟时间更短。骨架和生命周期另经过只读独立核验，最终玩法与重置由主代理在浏览器运行。

## 短时性能采样

每组预热约 2.5 秒、正式采样 20 秒，两组串行运行。压力场景含 20 平民、12 追捕单位、持续镭射和受限物理碎片。

| 场景 | 帧数 | 帧时间中位数 / P95 | 最长帧 | CPU 更新中位数 / P95 | 渲染命令提交中位数 / P95 |
|---|---:|---:|---:|---:|---:|
| 普通飞行探索 | 1210 | 16.7 / 16.7 ms | 16.8 ms | 0.8 / 1.0 ms | 3.1 / 3.9 ms |
| 三级追捕与效果 | 1208 | 16.7 / 16.8 ms | 16.8 ms | 1.3 / 1.7 ms | 4.4 / 5.6 ms |

两组短时采样约为 60 FPS，均无 pageerror。渲染提交时间是 CPU 发出渲染命令的时间，不是独立 GPU 耗时；帧时间来自 requestAnimationFrame 的实际间隔。

## 完整持续运行与生产预览

30 秒预热，普通探索 120 秒、三级追捕/战斗/破坏 120 秒，再继续运行 360 秒；后半段三次重置，总计约 10.5 分钟。两组正式采样期间没有其他测试浏览器并发。

| 场景 | 帧数 | 中位数 / P95 | 最长帧 | CPU 更新中位数 / P95 | 渲染提交中位数 / P95 |
|---|---:|---:|---:|---:|---:|
| 普通探索，120 秒 | 7214 | 16.7 / 16.7 ms | 16.8 ms | 0.8 / 1.1 ms | 3.2 / 4.2 ms |
| 三级追捕/战斗/破坏，120 秒 | 7189 | 16.7 / 16.7 ms | 450 ms | 1.5 / 2.1 ms | 4.9 / 6.7 ms |

中位数和 P95 满足实施计划的普通与压力场景指标。压力组存在约 450 ms 的单次长帧，渲染提交也出现约 456 ms 峰值；原因未单独定位，不能据此宣称全程没有顿挫。

三次重置都恢复 29 刚体、87 碰撞体、20 平民、0 敌人、0 特效，固定菜单视角下均为 334 几何、49 纹理。长时间预热看过的源资产更多，因此此测试的资源基线与单独视觉回归的 240/36 不同；各自重复重置均稳定。三次重置后的 JS 堆为 86.5、83.3、93.1 MiB，最终约 94.0 MiB；短期 GC 波动不能证明任意时长的内存稳定性。整个运行无 pageerror。

完整采样完成后修正了 OBJ/glTF 贴图方向、鞋子覆盖和领口；这些最终资产另外重复短时采样、视觉回归和生产加载检查。完整报告属于修正前的蒙皮视觉版本，保留该测试顺序以便复核。

最终资产上重新运行集成 10 项、扩展 7 项、生产补测 7 项和视觉回归 8 项，共 32 项浏览器检查全部通过，无 pageerror。实际键鼠覆盖飞行、升降、冲刺、镭射、右键重拳、Q 砸地与暂停；另覆盖缺失模型重试、完整墙体遮挡、屋顶落地、边界返回、补兵与空中射击。生产包在 `http://127.0.0.1:4173/` 成功加载并进入街区。

生产角色展示页另验证了四类角色切换、飞行/待机姿态切换与截图，无运行时异常，生产环境没有 `window.game` 或 `window.studio` 开发对象。结果在 `.artifacts/production-studio.json`，截图为 `production-character-front.png` 与 `production-character-fly.png`。
