## 需要证明的结果

- 角色在道路、路沿、人行道、墙边与地图边界能正常前进、沿障碍滑动和返回；高速移动不能穿透完整主体。
- 60、120、144 Hz 以及不均匀帧时间下，悬停、匀速与加速飞行、转弯的角色与镜头连续，无物理步引起的交替跳动。
- 待机、移动、奔跑、转向、起飞、悬停、加速、降落、重拳与砸地均有自然姿态与过渡；落地/攻击收势完整播放。
- 模型、服装、鞋子、肩饰和披风在上述状态中贴合，角色与街景碰撞符合可见几何，不出现持续或明显穿模。
- 街景具备可信比例、建筑变化、真实表面细节、完整近中远景与街道陈设；角色材质与服装达到同一观感。
- M2 Pro / Chrome 保持可玩帧率，压力场景、重置和长时间运行保留测量；核心玩法回归通过。
- 交付可播放、可对外分享的实际游玩 MP4 录屏，展示街景、连续运动/飞行、能力与追捕；视频不冒充另一个渲染器的画面。
