## 输入与生成方式

- 工具：内置 `image_gen.imagegen`，每件资产分别生成一次；工具未返回可核验的底层模型版本。
- 风格与类别参考：[北京场景原板](../beijing-xierqi-qinghe-scene-v1.png)，作为参考输入；本轮并非从原板低分辨率对象直接裁切。
- 设计：沿用银灰轿车、蓝白公交和蓝黑两轮车的类别与配色；原板没有足够细节的部分由单体设计补全，不代表真实品牌或具体车型复刻。
- T03：本轮选择适合车壳生成的踏板式电动车，无人骑乘，不采用细管共享自行车方案。
- 每张均为一物一视角，白底、柔和中性光照、无人物、无文字标签、完整轮廓；T01/T03 为前左三分之四视角，T02 展示前部与有乘客门的右侧。
- 保留工具的原始 PNG 输出，未裁切、放大或再次压缩。白底不等于透明背景。

## 用法与检查结果

选择相应 PNG 单独作为 Tripo 图生模型的主参考，不把三张拼成一张上传。完整提示词为可追溯生成记录，不是图片的一部分。

主代理及独立视觉核验均确认：三图的车身、可见车轮与后视镜完整入镜，无明显重复车轮、断开部件或严重扭曲；公交可见两轴和右侧两组乘客门，踏板车可见前后两轮与连续车架。

这些是单视角外观参考，未显示部分仍需后续检查；生成模型后按[资产分工方案](../../../docs/BEIJING_SCENE_ASSET_PLAN.md)在 Blender 中检查尺度、后侧结构、车轮/玻璃拆分、拓扑和碰撞体。T03 后轮侧的传动/电机护罩需要结合最终电动车设计复核。尚未向 Tripo 上传、生成 3D 模型或接入游戏。
